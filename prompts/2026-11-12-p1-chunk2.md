## Bước 2 — Implement (trong crates/minewrap-gui)

Tham chiếu ĐÚNG các component Svelte trong `ui/src/components/` (đọc trực
tiếp để đủ field — dưới đây là bản tóm tắt đã verify):

1. **Add-instance wizard** (tham chiếu `Wizard.svelte` + `JavaPicker.svelte`
   + `AddInstance.svelte`): một dialog/tab form gồm:
   - ID (bắt buộc, mono), Display name (tuỳ chọn), Work dir (mono + nút
     "Scan" gọi `scan_work_dir`/`scan_launch`, hiển thị kết quả quét +
     chọn jar), Java path (JavaPicker: gọi `detect_java`, list + chọn +
     custom path), Min RAM / Max RAM (MiB, number, 256–65536), Preset
     (select: none / aikar / custom), Launch mode (select: jar /
     args-file / custom), Launch args (mono), Auto-start (checkbox).
   - Validate: id không trùng instance đang có (dùng list hiện có), min ≤
     max RAM, work_dir không rỗng. Lỗi hiển thị inline, không đóng form.
   - Submit → `add_instance` (RemoteClient) → thành công: đóng form,
     instance mới xuất hiện ở sidebar; thất bại: hiện lỗi trong form.
   - Sau khi thêm: nút **Remove** instance (kèm confirm — mirror nút
     Remove danger trong App.svelte) → `remove_instance`.
2. **Settings screen** (tham chiếu `Settings.svelte`): panel cho instance
   đang chọn:
   - Group "Instance": Display name, Work dir, Java path (JavaPicker),
     Min/Max RAM, Preset (select), Extra JVM args (multiline, 1 dòng/arg),
     Launch mode (select), Launch args, Auto-start.
   - Group "Probe": Host, Port, Timeout (s), Query enabled.
   - Group "Restart": Policy (select: never/on-failure/always… — đọc đúng
     enum trong config.rs), Max retries, Backoff base (s), Backoff max (s),
     Reset after online (s).
   - Dirty tracking: đổi gì → "Unsaved changes"; Save → `update_config` →
     "Saved."; switch instance khi dirty → confirm discard (Slint dialog).
   - Load qua `get_config`; map đủ field 2 chiều (form ↔ InstanceConfig).
3. Navigation & UX: sidebar giữ nguyên; thêm nút "Add instance"; chọn
   instance + tab/pane Settings. Enter = submit trong form, Esc = cancel.
   Theo pattern state 2 chiều đã chứng minh ở chunk 1.
