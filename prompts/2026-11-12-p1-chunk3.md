## Bước 2 — GUI: 3 tab mới + theme tokens (crates/minewrap-gui)

Tham chiếu component Svelte (đọc trực tiếp để đủ field):
`ui/src/components/Properties.svelte`, `Mods.svelte`, `Notifications.svelte`.

1. **Tab Properties** (raw editor, như Properties.svelte):
   - TextEdit multiline mono chứa text server.properties; load qua
     `read_properties`; Save qua `write_properties`.
   - Dirty tracking như Settings: status "Unsaved changes"/"Saved.";
     Save disabled khi !dirty; nút Revert (đưa về text đã load).
   - Lỗi 404 "server.properties not found" → hiển thị thông báo thân thiện
     trong panel ("No server.properties in work dir"), KHÔNG panic.
   - Switch instance khi dirty → confirm discard (XEM LUU Ý DIALOG dưới).
2. **Tab Mods** (như Mods.svelte):
   - Danh sách (ScrollView/ListView) từ `list_mods` (ModDto); mỗi dòng:
     tên (mono), enabled/disabled, nút Enable/Disable → `toggle_mod` →
     refresh; busy state từng dòng ("Working…").
   - Search filter: LineEdit, filter theo tên case-insensitive.
   - Header: "N mods · M enabled".
   - mods dir không tồn tại → daemon tự tạo rỗng: hiển thị danh sách rỗng
     + gợi ý "Drop .jar files into <work_dir>/mods/".
3. **Tab Notifications** (như Notifications.svelte; DiscordConfig trong
   crates/minewrap-core/src/config.rs ~L326):
   - Fields: enabled (CheckBox), mode (ComboBox: edit-in-place /
     new-message), interval_seconds, first_push_delay_seconds, log_lines,
     max_log_chars, state_change_posts (CheckBox),
     state_change_debounce_seconds, redact_regexes (multiline, 1 dòng/
     entry, bỏ dòng rỗng).
   - Webhook WRITE-ONLY: hiển thị "A webhook URL is stored." khi
     webhook_set=true / "No webhook stored." khi false; LineEdit "New
     webhook URL (write-only)" — chỉ đưa `discord.webhook_url` vào patch
     khi người dùng nhập giá trị mới; sau Save xóa field nhập.
   - Nút "Send test" → `discord_test` → hiện kết quả (ok=true → "Test
     sent."; ok=false → error message từ response).
   - Dirty tracking + Save/Revert như Settings; Save = `update_config`
     patch group discord.
4. **Theme tokens**:
   - Trích xuất màu / spacing / font-size đang hard-code trong main.slint
     vào `export global Theme { … }` (đầu main.slint hoặc file riêng +
     `import`).
   - Thay literal bằng `Theme.xxx`. KHÔNG đổi giá trị — diện mạo giữ nguyên.
5. **Cấu trúc tab**: `settings-tab` int 0..4 (0 Console / 1 Settings /
   2 Properties / 3 Mods / 4 Notifications). Tab row 5 nút vẫn vừa cửa
   sổ ~936px (nếu chật: giảm padding nút, KHÔNG giảm cỡ chữ dưới 12px).
   Console giữ direct-layout; 4 panel kia = absolute overlay y=92px,
   `visible: root.settings-tab == N` (nhớ: `visible` KHÔNG ảnh hưởng
   layout — chỉ đúng với absolute overlay; KHÔNG bọc layout con trong
   Rectangle ẩn rồi kỳ vọng nó chiếm chỗ).

LƯU Ý DIALOG: ưu tiên inline confirm row trong panel (pattern C2 dùng
Slint dialog được thì giữ; nhưng nếu cần dialog/window mới: tạo LAZY
trong callback — bài học wizard). StandardButton trong dialog hiện có
thể dùng lại nếu đã chứng minh ở C2.
